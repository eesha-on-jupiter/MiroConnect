# HTTP

Components that call the Miro REST API. Reads run on recompute; every write is button-triggered.

| Tab | Description |
|---|---|
| [Boards](Boards/index.md) | Find, read, create and delete boards. |
| [Items](Items/index.md) | Create, read, list and delete board items. |
| [Connectors](Connectors/index.md) | Create, read and delete connector lines between items. |
| [Tags](Tags/index.md) | Create tags, attach or detach them, read an item's tags. |
