# Boards

Find, read, create and delete Miro boards. Create Board and Delete Board only fire on a button click.

| Component | Description |
|---|---|
| [Find Board](FindBoardComponent.md) | Lists every accessible board and optionally matches one by name. |
| [Get Board](GetBoardComponent.md) | Reads a board's name, team and creation date. |
| [Create Board](CreateBoardComponent.md) | Creates a new board in a team. |
| [Delete Board](DeleteBoardComponent.md) | Deletes a board by ID. |
