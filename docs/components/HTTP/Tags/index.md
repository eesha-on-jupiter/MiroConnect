# Tags

Tags are board-level labels: create them on the board first, then attach them to items. Create Tag, Attach Tag and Detach Tag only fire on a button click.

| Component | Description |
|---|---|
| [Get Item Tags](GetItemTagsComponent.md) | Reads the IDs and titles of the tags on one item. |
| [Create Tag](CreateTagComponent.md) | Posts a list of tag JSONs to a board. |
| [Attach Tag](AttachTagComponent.md) | Attaches one tag to a list of items. |
| [Detach Tag](DetachTagComponent.md) | Removes one tag from a list of items. |
