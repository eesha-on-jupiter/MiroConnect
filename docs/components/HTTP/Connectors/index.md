# Connectors

Create, read and delete connector lines between board items. Create Connector and Delete Connector only fire on a button click.

| Component | Description |
|---|---|
| [Get Connector](GetConnectorComponent.md) | Reads a connector's start and end item IDs. |
| [Create Connector](CreateConnectorComponent.md) | Posts a list of connector JSONs to a board. |
| [Delete Connector](DeleteConnectorComponent.md) | Deletes a list of connectors by ID. |
