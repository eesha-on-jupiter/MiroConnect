# Items

Create, read, list and delete items on a Miro board (sticky notes, shapes, text, cards, frames, images). Create Item and Delete Item only fire on a button click.

| Component | Description |
|---|---|
| [Get Item](GetItemComponent.md) | Reads one item's type, position and size. |
| [Get All Items](GetAllItemsComponent.md) | Lists item IDs on a board, optionally filtered by type. |
| [Create Item](CreateItemComponent.md) | Posts a list of item JSONs from the Items JSON tab to a board. |
| [Delete Item](DeleteItemComponent.md) | Deletes a list of items by ID. |
