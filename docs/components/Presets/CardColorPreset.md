# Card Color

A value-list preset of card theme hex colors, for [Card Style](../JSON/Style/CardStyleComponent.md)'s `Card Color` input.

## Inputs

None.

## Outputs

One unnamed value-list output: the selected entry's value as text.

## Values

| Display Name | Value |
|---|---|
| Default | `#e6e9ef` |
| Red | `#f24726` |
| Orange | `#ff9f00` |
| Yellow | `#ffd500` |
| Green | `#1db747` |
| Dark Green | `#0ca678` |
| Cyan | `#00c2e0` |
| Blue | `#2d9bf0` |
| Violet | `#9510ac` |
| Pink | `#ff5c74` |

## Feeds into

- [Card Style](../JSON/Style/CardStyleComponent.md) `Card Color`.
