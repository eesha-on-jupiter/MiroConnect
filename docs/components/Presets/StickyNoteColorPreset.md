# Sticky Note Color

A value-list preset of Miro's named sticky note colors, for [Sticky Note Style](../JSON/Style/StickyNoteStyleComponent.md)'s `Fill Color` input.

## Inputs

None.

## Outputs

One unnamed value-list output: the selected entry's value as text.

## Values

| Display Name | Value |
|---|---|
| Gray | `gray` |
| Light Yellow | `light_yellow` |
| Yellow | `yellow` |
| Orange | `orange` |
| Light Green | `light_green` |
| Green | `green` |
| Dark Green | `dark_green` |
| Cyan | `cyan` |
| Light Pink | `light_pink` |
| Pink | `pink` |
| Violet | `violet` |
| Red | `red` |
| Light Blue | `light_blue` |
| Blue | `blue` |
| Dark Blue | `dark_blue` |
| Black | `black` |

## Feeds into

- [Sticky Note Style](../JSON/Style/StickyNoteStyleComponent.md) `Fill Color`.

## Notes

- Sticky notes accept these names only, not hex colors.
