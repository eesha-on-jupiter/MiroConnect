# Presets

Value-list shortcuts for Miro's enum-like string fields, so you are not guessing at literal API values. Each is a Grasshopper value list: pick an entry and wire its output into the matching input.

| Component | Description |
|---|---|
| [Shape Type](ShapeTypePreset.md) | 18 Miro shape types, for [Shape JSON](../JSON/Items/ShapeJsonComponent.md). |
| [Sticky Note Color](StickyNoteColorPreset.md) | 16 named sticky note colors, for [Sticky Note Style](../JSON/Style/StickyNoteStyleComponent.md). |
| [Card Color](CardColorPreset.md) | 10 card theme hex colors, for [Card Style](../JSON/Style/CardStyleComponent.md). |
| [Font Family](FontFamilyPreset.md) | 10 Miro font families, for [Text Style](../JSON/Style/TextStyleComponent.md). |
| [Stroke Style](StrokeStylePreset.md) | 3 connector dash patterns (solid, dashed, dotted), for [Connector Style](../JSON/Style/ConnectorStyleComponent.md). |
