# Geometry

Build where items go: center position, size, rotation and parent frame. Every Items JSON component takes these as `Position JSON` and `Parent JSON`. No network calls.

| Component | Description |
|---|---|
| [Position](GeometryComponent.md) | One Position JSON from center X/Y, width, height and rotation. |
| [Grid](GridComponent.md) | A list of Position JSONs laid out in rows. |
| [Offset](OffsetComponent.md) | Shifts an existing Position JSON by X and Y. |
| [Parent](ParentComponent.md) | Parent JSONs from frame IDs, to place items inside frames. |
