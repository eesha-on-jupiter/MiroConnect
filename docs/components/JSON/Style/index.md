# Style

One style-object builder per item type. Each emits a single Style JSON for the matching Items JSON component's `Style JSON` input; one style is reused for every item in the batch. No network calls.

| Component | Description |
|---|---|
| [Sticky Note Style](StickyNoteStyleComponent.md) | Fill color, text alignment and font size for sticky notes. |
| [Shape Style](ShapeStyleComponent.md) | Fill, border color, border width and font size for shapes. |
| [Text Style](TextStyleComponent.md) | Fill, font family, font size and alignment for text items. |
| [Card Style](CardStyleComponent.md) | Theme color for cards. |
| [Frame Style](FrameStyleComponent.md) | Fill and border color for frames. |
| [Connector Style](ConnectorStyleComponent.md) | Line routing, stroke color and stroke width for connectors. |
