# JSON

Pure JSON assembly with no network calls: safe to leave wired up and recomputing freely.

| Tab | Description |
|---|---|
| [Geometry](Geometry/index.md) | Positions, grids, offsets and frame parents shared by every item type. |
| [Items JSON](Items/index.md) | One request-body builder per item type, plus connectors and tags. |
| [Style](Style/index.md) | One style-object builder per item type. |
